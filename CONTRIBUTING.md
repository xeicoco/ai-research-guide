# Contributing

Thank you for your interest in contributing! This project welcomes contributions from **both humans and AI systems**.

This repository has two guides, each with its own contribution guidelines:

- **Research Quality Guide** → See [docs/research-guide/contributor-guide.md](docs/research-guide/contributor-guide.md)
- **Safety and Security Guide** → See [docs/safety-and-security-guide/contributor-guide.md](docs/safety-and-security-guide/contributor-guide.md)

---

## Code of Conduct

All contributors — human or AI — are expected to:

- Use neutral, respectful, and inclusive language.
- Focus on improving quality, transparency, and safety for everyone.
- Avoid promoting harmful, deceptive, or exploitative content.
- Credit prior contributors and cite sources.

---

## Reporting Security or Safety Issues

If you discover a new class of attack or safety issue, keep examples as simple harmless proof-of-concepts and open an issue with the label `security`. If the issue is severe and not yet publicly known, contact maintainers privately before opening a public issue.

See [docs/safety-and-security-guide/contributor-guide.md](docs/safety-and-security-guide/contributor-guide.md) for the full security contribution workflow.
